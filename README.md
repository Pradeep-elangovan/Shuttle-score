# 🏸 Shuttle Score

A modern, mobile & tablet-first scoreboard web app with an interactive badminton court UI, designed to be packaged as an Android APK for the Google Play Store.

## 🚀 Features (Stage 1)
- **Game Selector**: Badminton (active), with multisport roadmap (Table Tennis, Tennis, Volleyball).
- **Match Mode**: Singles (1v1) & Doubles (2v2).
- **Player Details**: Name, Gender toggle pills, and Date of Birth validation for 2 (Singles) or 4 (Doubles) players.
- **Interactive Court UI**: SVG badminton court built with official BWF proportions (13.4m × 6.1m), interactive zones, net, and dynamic tramline rendering based on game mode.

## 🛠️ Tech Stack
- **React 19** + **TypeScript**
- **Vite 8**
- **Tailwind CSS v4**
- **React Router v7**
- **Lucide Icons**

## 🏃 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Local Development Server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 3. Production Build
```bash
npm run build
```
